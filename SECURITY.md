# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.3.x | Yes |
| < 0.3.0 | No |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities (such as PII/PCI detection
bypasses, evidence masking leaks, or ReDoS issues in compliance regexes).

Instead, report vulnerabilities privately via GitHub Security Advisories:
https://github.com/sankaranainar-p/agent-invariant-eval/security/advisories/new

Include a minimal reproduction (input payload, invariant configuration, and observed vs. expected
behaviour). We will acknowledge reports within 5 business days and coordinate a fix before public
disclosure.
